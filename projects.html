Amazon Sustainability Classifier
Large-scale NLP pipeline · Python, Hadoop, BERT, Scikit-learn
  • Built a distributed text processing pipeline on Hadoop, using MapReduce to batch-process 1,000+ Amazon customer reviews across commodity hardware.
  • Handled end-to-end data wrangling with Pandas and NumPy — tokenization, null handling, and feature transformation to prepare model-ready inputs.
  • Fine-tuned BERT embeddings for sentiment classification (positive/negative/neutral), improving precision over a TF-IDF baseline.
  • Designed a multi-label classification layer to tag products as sustainable or non-sustainable from aggregated review signals.

Multimodal Grocery Recognition
Fusion classification pipeline · Python, OpenCV, Scikit-learn, OCR, RAG, Gemini LLM
  • Built a data fusion pipeline combining OCR-extracted text features with image-based visual features to classify grocery items.
  • Benchmarked multiple classifiers (SVM, Logistic Regression, Random Forest), achieving ~90% accuracy on the final model.
  • Integrated a RAG pipeline with the Gemini LLM to generate contextual product insights from extracted label and packaging data.
  • Added EU Nutri-Score computation from extracted nutritional data, giving each product an at-a-glance health rating.
  • Built an allergen detection layer that flags common allergens from ingredient lists automatically.
  • Created a modular preprocessing pipeline for feature extraction and normalization, reusable across classification tasks.
  • Deployed as an interactive Streamlit web app on Streamlit Community Cloud, with version control via Git/GitHub.
