SafeScan
LLM-driven multimodal product recognition with allergen detection · Python, TensorFlow, ResNet50, EasyOCR, Gemini API, RAG
  • Built a two-stage pipeline: ResNet50 image embeddings fused with TF-IDF OCR text features feed a dense neural network that classifies ~11,900 grocery product images into 21 categories, reaching 88.74% test accuracy.
  • Integrated the Gemini API as an LLM reasoning layer with engineered prompts to detect allergen conflicts against a user allergy profile from noisy OCR ingredient text, returning a structured Safe / Conflict / Uncertain verdict.
  • Grounded LLM outputs with RAG over the Open Food Facts API and a deterministic allergen-ontology check, and highlighted conflicting ingredients on the product image using OCR bounding boxes.
  • Computed health grades with the published Nutri-Score algorithm (LLM used only for nutrient extraction) and added Mondrian conformal prediction for calibrated 90% confidence sets.
  • Hardened for production: exponential-backoff retries, separate handling of 401 / 429 / 404 / 503 API errors, and graceful degradation so a failed LLM call still returns classification and ontology results.
  • Deployed as an interactive Streamlit web app on Streamlit Community Cloud.

StyleMate
Fashion recommender Android app · Android, Firebase, OpenCV, K-Means
  • Built an Android app that analyzes a clothing photo from the camera or gallery and suggests matching outfits based on its colors.
  • Extracted dominant colors using OpenCV K-Means clustering (k = 3 on images resized to 200×200), then mapped each cluster to the nearest of 16 named colors using Euclidean distance in RGB space.
  • Designed a rule-based recommendation engine that combines the detected color, outfit category, and the user's saved style preferences.
  • Implemented sign-up, login, and password reset with Firebase Authentication, and stored user profile details in Firestore under each user's UID.
  • Designed the full UI flow (login → profile details → home) with a tabbed layout for capturing outfits, viewing results, and browsing a tops/bottoms wardrobe.
  • Hardened the app against crashes with null checks, Firestore document-existence checks, bitmap validation, and K-Means output checks.
